# Reclaiming Shalom - Website Rebuild

A modern, clean redesign of the Reclaiming Shalom website featuring a standard navigation menu (replacing the drawer/hamburger menu) and improved user experience.

## Features

- **Standard Navigation Menu**: Clean, horizontal navigation bar that's always visible
- **Responsive Design**: Mobile-first approach that works beautifully on all devices
- **Modern Aesthetics**: Maintains brand colors and identity with fresh, contemporary design
- **Performance Optimized**: Vanilla HTML/CSS/JS for fast load times
- **Accessible**: Semantic HTML and ARIA-friendly structure

## Project Structure

```
reclaiming-shalom-rebuild/
├── index.html          # Main homepage
├── css/
│   └── styles.css      # All styles and responsive design
├── js/
│   └── main.js         # Interactive functionality
└── README.md           # This file
```

## Color Scheme

- **Primary Green**: `#4a7023` - Represents growth and healing
- **Dark Gray**: `#202020` - Main text color
- **Orange Accent**: `#f76a0c` - Call-to-action elements
- **Light Gray**: `#f5f5f5` - Section backgrounds

## Typography

- **Headings**: Barlow (Bold, 700 weight)
- **Body**: Poppins (Regular, 400-500 weight)

## Key Sections

1. **Hero Section**: Eye-catching introduction with clear call-to-action
2. **What is Shalom?**: Educational content explaining the concept
3. **What Happened to Shalom?**: Narrative about trauma and recovery
4. **Recent Articles**: Grid layout showcasing blog posts
5. **Certification**: Professional credentials display
6. **Footer**: Quick links and contact information

## Development

This is a static website built with:
- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript (ES6+)

No build process or dependencies required. Simply open `index.html` in a browser to view locally.
